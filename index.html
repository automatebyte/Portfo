KreditAI — AI-Powered Loan Management System

A multi-tenant loan management platform built for financial institutions, designed around banking-grade security and compliance requirements. Implements strict tenant data isolation, role-based access control (RBAC), and JWT authentication to ensure secure, auditable access across all user roles.

Covers the full loan lifecycle — client onboarding, loan application processing, credit approvals, and real-time status tracking — through dedicated administrative dashboards and client portals. PostgreSQL handles relational data modeling; Redis and Celery manage background task queuing and caching for responsive performance under load. The application is fully containerised with Docker and Docker Compose, supporting consistent, reproducible deployment across environments.
